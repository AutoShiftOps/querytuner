# API Reference

This file is intentionally minimal. The authoritative, always-current API reference is
the live Swagger/OpenAPI UI, generated directly from the backend's Pydantic models and
route definitions — it can't drift out of sync with the actual API the way a hand-written
doc can.

**Live docs:** https://api.querytuner.com/docs
**OpenAPI schema (JSON):** https://api.querytuner.com/openapi.json

For a quick-start example (a plain heuristics-only call and an AI-enabled call), see the
"Live API" section of the root [README.md](../README.md).

For known gaps, scope boundaries, and rate limits, see
[backend/LIMITATIONS.md](../backend/LIMITATIONS.md).
